# ConstructionOS: Procurement & Inventory

## Procurement Workflow

1. **Material Request (PR)**
   - Generated by Site Engineer based on Activity planned quantities.
   - Triggers approval workflow based on item cost and budget availability.

2. **RFQ & Quotation Comparison**
   - Approved PRs are grouped into Requests for Quotation (RFQs) by the Procurement Manager.
   - System auto-generates quotation comparison sheets based on vendor responses.

3. **Purchase Order (PO)**
   - Finalized contract with a vendor.
   - Includes Delivery terms, Payment terms, and Taxation (GST).
   - Supports Amendments with strict version control.

4. **Goods Receipt Note (GRN)**
   - Created at the site when material arrives.
   - Includes quantity check and initial quality check.
   - Auto-updates the Inventory Ledger upon acceptance.

## Inventory Architecture

- **Store Hierarchy:** Central Warehouse -> Site Store -> Sub Store.
- **Inventory Ledger:** An immutable, append-only table recording every material movement (`RECEIPT`, `ISSUE`, `TRANSFER`, `RETURN`, `SCRAP`).
- **Stock Balances:** Maintained via database triggers on the `inventory_ledger` to ensure absolute consistency.
- **Site Issues:** Materials issued to specific Activities/Cost Codes to calculate real-time "Consumed Cost".
- **Dead Stock Analysis:** Materialized views track items with no movement over 90 days.
