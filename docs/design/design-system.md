# ConstructionOS: Design System

## Core Guidelines

- **Theme:** Dark mode default, utilizing deep slates (`bg-slate-950`).
- **Glassmorphism:** Panels use translucent backgrounds (`bg-white/5`) with backdrop blur filters.
- **Typography:** `Inter` for standard text, `JetBrains Mono` for tabular data.
- **Framework:** Strict Tailwind CSS. No external animation libraries. Heavy focus on CSS Grid and Flexbox for responsive, dense data layouts.
